# Sample Question PDFs

Place your question PDFs in this folder or upload them through the web interface.

## Expected PDF Format

Each question should follow this format:

```
1. What is the value of 15 × 12?
A) 170
B) 180
C) 190
D) 200
Answer: B
Explanation: 15 × 12 = 15 × 10 + 15 × 2 = 150 + 30 = 180

2. What is the next number in the sequence: 2, 6, 18, 54, ?
A) 108
B) 162
C) 72
D) 216
Answer: B
Explanation: Each number is multiplied by 3. So 54 × 3 = 162.
```

## Supported Formats

- Numbered questions: `1.` or `1)`
- Q-prefix: `Q:` or `Q.`
- Options: `A)`, `A.`, or `A:`
- Answer line: `Answer: B`
- Explanation line (optional): `Explanation: ...`
